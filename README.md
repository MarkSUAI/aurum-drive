## 📌 О проекте
**«AURUM DRIVE»** — современный коммерческий одностраничный веб-лендинг сервиса премиального каршеринга и посуточной аренды суперкаров без оклейки и опознавательных знаков в Санкт-Петербурге.

Проект разработан с соблюдением принципов семантической верстки HTML5, модульной архитектуры стилей CSS3 и нативного JavaScript (ES6+), а также развернут с использованием системы контроля версий Git и хостинга GitHub Pages.

---

## 🏎️ Автопарк сервиса
В каталоге представлены 5 флагманских суперкаров с подробными тактико-техническими характеристиками:
1. **Porsche 911 Carrera 4S (992)** — 450 л.с., 3.4 сек до 100 км/ч, полный привод.
2. **Mercedes-AMG GT 63 S 4-Door** — 639 л.с., 3.2 сек до 100 км/ч, 4MATIC+ Drift Mode.
3. **BMW M8 Gran Coupe Competition** — 625 л.с., 3.2 сек до 100 км/ч, M xDrive.
4. **Audi RS6 Avant C8** — 600 л.с., 3.6 сек до 100 км/ч, quattro.
5. **Porsche Taycan Turbo S** — 761 л.с., 2.8 сек до 100 км/ч, 100% электро.

## 🛠️ Технологический стек
- **HTML5:** семантические структурные теги (`<header>`, `<main>`, `<section>`, `<article>`, `<footer>`, `<dialog>/modal`).
- **CSS3:** адаптивная верстка (CSS Grid + Flexbox), палитра глубокого графита (`#090b10`) и шампанского золота (`#c5a059`), эффект стекломорфизма (`backdrop-filter`), CSS-переменные, микроанимации.
- **JavaScript (Vanilla ES6+):** валидация и обработка формы бронирования, интерактивное модальное окно подтверждения заявки, плавная навигация, мобильное гамбургер-меню.
- **Инструменты версионирования и деплоя:** Git, GitHub, ветвление (`main`, `add-car-photos`, `improve-ui`), Pull Requests, GitHub Actions, GitHub Pages.

## 🚀 Локальный запуск
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/MarkSUAI/aurum-drive.git
   ```
2. Откройте папку проекта в **Visual Studio Code**.
3. Запустите локальный сервер через расширение **Live Server** (кнопка `Go Live` на порту 5500) или просто откройте `index.html` в любом современном браузере.
